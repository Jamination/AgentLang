## For other areas

- **lib (src/prelude.al), memory safety**: core `alloc[T](n)` does not check `n * sizeof[T]()` for overflow. `x := alloc[i64](1 << 61); print(len(x))` prints 2305843009213693952: a slice of 2^61 elements over almost no memory, whose checked indexing can reach any address. Same pattern as bug 05 in std.mem. Repro: tmp/bugs/std/lib-alloc-overflow.al. (Main says this is already fixed on bug-lib.)
- **lib**: prelude f64 `floor(-0.0)` and `ceil(-0.5)` returned +0.0 (found by tmp/fz/mathfz.py). BugLib has fixed these on bug-lib. With that fix, std.math `fract(-0.0)` also becomes +0.0, as in C.

## Checked and found correct

- fd-creating sites in std: os pipes and memfd already used O_CLOEXEC; read_bytes/list_dir/gamepad_open fixed (17); ALSA, Xlib and libwayland open their own descriptors (close-on-exec in those libraries).

- std.image: PNG/BMP decoders under a mutation fuzzer (tmp/fz/pngfz.py: 100k files, generated by Python with all colour types, depths 1-16, Adam7, tRNS, split IDATs; mutations with and without CRC repair) — no crash, no hang, pixels of all valid files equal a Python reference decoder.
- std.image: inflate / zlib_decompress / inflate_into / zlib_decompress_into vs Python zlib on valid and mutated streams (tmp/fz/zfz.py), fixed buffers of sizes 0..len+8 (no write past the buffer), deflate/zlib_compress round trips and the documented size bound.
- std.asset JSON: differential fuzzer vs Python `json` (tmp/fz/jfz.py, 23k documents) after fix 01; nesting limit 200, 100000 levels rejected without stack overflow.
- std.asset files: make_dir with parents / trailing slash / over a file, read_bytes of a directory, an empty file, /proc files, list_dir sorted, on a file (ENOTDIR), 4096+ byte paths (error 36), io_error after each.
- std.os: fds inherited by children (only 0-2), 10 MB stdout + 3 MB stderr captured, run_capture_all, signal deaths (139), exec format error (8), directory (13), empty argv (22), empty name (2), argv with empty strings and spaces, PATH with empty / relative / missing entries and unset PATH, spawn/try_wait/kill/wait twice, Process{}, shm_create(-1), map_shared size 0, close_fd twice.
- std.rand: rng(0) state = splitmix64 reference, doc value of rng(0).next_u64, `below` with n = 3 * 2^30 unbiased, noise2/noise3 range over 2M samples.
- std.audio: WAV decoder under mutation fuzzing (tmp/fz/wavfz.py, 24k files, 8/16/24/32-bit PCM, f32/f64, extensible headers, extra chunks): no crash.
- std.math: 19 scalar functions x f32/f64 against glibc on 110k random plus special inputs (tmp/fz/mathfz.py). Everything is within 1 ulp except f64 tan (bug 10) and the signed zeros (bug 09). Also the vec/mat/quat functions against numpy over 300 random cases: determinant, inverse, inverse_affine, mat4_from_quat, to_euler/quat_euler and axis_angle round trips, slerp, quat_look_rotation. All agree to f32 precision. Easing endpoints map 0 to 0 and 1 to 1. `normalize` of zero stays zero.
- std.image encoders: png_encode/bmp_encode round trips on 400 random images (1-4 channels), and Python zlib validated every CRC and IDAT stream. deflate speed is fine on adversarial data (faster than zlib -6 on a 3-symbol random input; no cliff). crc32/adler32 continuation was checked at every split point against Python.
- std.window: `fit_rect`/`blit_fit` over 20k random sizes, including extreme aspect ratios: no out-of-bounds access, the rectangle is always inside. The keysym table and the X11 struct offsets (XKeyEvent, XConfigureEvent, XClientMessageEvent, Visual, XSizeHints, XColor) match Xlib.h.
- std.input: edge logic (down/up/down within one frame, repeat without down, unfocus), gamepad event decoding, EventQueue capacity.
- std.mem: Pool generations (wrap keeps parity), clear, growable pools; SparseSet; Arena release/reset.
- Generators: `gen_vk --verify` (1475 layout lines), `gen_wayland --verify` (633 lines), `gen_dx12 --verify` (mingw static assertions). All pass, and their outputs are byte-identical to the committed files (`git status` clean). tests/sys/wayland ran against a private headless weston as part of tests/run.sh.

## Suspicions / notes not fixed

- `to_euler` near pitch ±90°: it snaps the pitch to exactly 90° when |sin(pitch)| > 0.99999. The rebuilt rotation can then be off by up to 0.0045 (0.26°). Without the snap, f32 noise breaks the decomposition entirely, so this is a design trade-off.
- `pow(sNaN, 0)`: AL gives 1 (C99), glibc gives NaN for a signalling NaN.
